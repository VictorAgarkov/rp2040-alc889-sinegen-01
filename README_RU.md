# Демонстрационный проект - интерфейс HDA-Link на RP2040

## О проекте

Данный проект демонстрирует возможность использования аудиокодеков с интерфейсом HDA-Link (например, ALC889) совместно с микроконтроллером RP2040 и его сопроцессорами PIO.

Для реализации интерфейса HDA-Link задействованы четыре конечных автомата (SM) с номерами от 0 до 3. В этом проекте они выполняют следующие функции:

0 – выход DOUT; 

1 – выход SYNC; 

2 – вход DIN, а также выходы BCLK и сигнала начала кадра (SoF); 

3 – обнаружение запроса адреса кодеком и назначение адреса.


*Назначение выводов RP2040:*
| RP2040 Pin | Signal      | ALC889 Pin | Note  |
|------------|-------------|------------|-------|
|     4      | SoF         |     -      | Debug |
|     5      | BCLK        |     6      |       |
|     6      | DOUT        |     5      |       |
|     7      | SYNC        |    10      |       |
|     8      | SDI         |     8      |       |
|     9      | RST         |    11      |       |
|    13      | DBGPIN1     |            | Debug |
|    14      | DBGPIN2     |            | Debug |
|    15      | DBGPIN3     |            | Debug |
|    16      | DBGPIN4     |            | Debug |
|    17      | DBGPIN5     |            | Debug |
|    20      | UART_TX_PIN |            |       |
|    21      | UART_RX_PIN |            |       |


Проект поддерживает все частоты дискретизации, поддерживаемые данным кодеком: 44,1; 48; 88,2; 96; 176,4 и 192 кГц.

По умолчанию используется максимально возможная частота 192кГц. Это определено в main.c:
```c
sbm = hdac_find_samplerate_base_mul(48000 * 4);
```
и может быть изменено на поддерживаемую кодеком частоту в Герцах.

В качестве демонстрации проект использует все 10 аудиовыходов для генерации независимых синусоидальных сигналов. Частоты задаются в массиве `gen_freq[10]`. Для режима 192 кГц частоты каналов с 0-го по 7-й изменяются в соответствии с геометрической прогрессией с множителем 1.5 - от 880 Гц (0,004583333333 × 192 000) до 15035,6 Гц; частоты каналов 8 и 9 равны 63936 Гц и 76800 Гц соответственно.

## Сборка из исходного кода
Процедура сборки из исходного кода аналогична той, что применяется для большинства проектов на базе RP2040. Предварительно должны быть установлены все необходимые для этого пакеты.

Клонирование и сборка:
```bash
git clone https://github.com/VictorAgarkov/rp2040-alc889-sinegen-01
cd rp2040-alc889-sinegen-01
cmake . -B build
make -j 8 -C build
```
Файлы прошивки (например, *rp2040-alc889-sinegen-01.uf2*) будут созданы в директории `build`.
